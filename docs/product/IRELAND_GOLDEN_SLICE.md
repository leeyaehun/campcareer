Career cohort and decision-readiness criteria are defined in

## Purpose

Ireland is the first deep validation market. Its purpose is to prove that a
user can move from a Career question to an explained degree and real education
options, with sources and trade-offs, before CampCareer expands breadth.

## What already works

- `/countries/ie` is public, canonical and source-backed for country
  planning context, salary/living-cost ranges, strong fields, visa context and
  institutions.
- Ireland methodology, national Path context and four Tier A city profiles
  (Dublin, Cork, Galway and Limerick) have explicit metric and comparison
  contracts.
- Ireland Career editorials cover the existing business, construction,
  education, engineering, health and technology cohorts without treating
  missing evidence as a score.
- The private Ireland program cohort contains 40 reviewed staging records and
  63 approved Career relations spanning 41 canonical Careers.

## Known disconnected or gated areas

- The Ireland program cohort is not a public program explorer/detail graph.
  Its program-level TrustEd/ILEP eligibility is not verified for any Tier A
  program; provider authorization is not substituted for program eligibility.
- Of the 40 staged rows, 28 are Tier B review-ready and 12 Tier C/restricted;
  this is not a public publication authorization.
- Country-level representative institutions are useful context but are not a
  claim that a program is delivered, open to an international learner or best
  for a Career.
- A public Career → Ireland degree → verified program path must not traverse a
  legacy/unverified offering as though it were ready.

## Validation journeys

Use these journeys only when every link is backed by the existing read model:

1. Technology income priority → Ireland country context → a source-backed
   Career → an eligible degree/program relation → official education evidence.
2. Healthcare stability priority → Ireland context → regulated Career Path →
   qualification and registration boundaries → verified education option.
3. Computer Science → Irish Career context → connected degree/program evidence
   → transparent alternative comparison.
4. Software Engineering Career → Ireland salary/demand evidence → Degree →
   official provider/program evidence and trade-offs.

No famous university is hardcoded as an expected winner. A missing verified
education link remains a visible gap.

## First build gate

The first Ireland implementation should be one high-intent, source-ready
Career/Degree slice, not a broad program explorer. It can proceed only after
the exact program-level eligibility, current official program identity,
location, study mode and relation evidence satisfy the established publication
gate. If those facts remain unavailable, improve the existing Career/Country
transition and make the education gap explicit instead.

Ireland passes the Golden Slice when a user can discover a Career, understand
why, reach an appropriate Degree and real education options, compare
alternatives, and inspect sources and trade-offs without a disconnected or
unsupported hop.
