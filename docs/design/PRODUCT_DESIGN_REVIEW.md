# Product Design Review

Last reviewed: 12 September 2026

Use this review monthly and before a material core-flow change. It evaluates
the existing Phase 3 system; it does not authorize a redesign because tastes
changed.

For each issue, attach observed user behaviour, feedback, error, accessibility
or performance evidence. Prioritize information hierarchy, decision clarity,
filter comprehension, comparison usability, visible source context and mobile
completion before cosmetic polish.

The permitted loop is:

`Problem → small UI improvement → measure / review`

Avoid added card chrome, unexplained totals, hidden source limitations,
mobile-only regressions, inaccessible controls and broad visual rewrites.
