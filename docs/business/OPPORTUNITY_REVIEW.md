# Business Opportunity Review

Last reviewed: 12 September 2026

Use one dated record for each proposed commercial opportunity. This is a
decision document, not a backlog item. Missing evidence remains missing.

## Review template

| Field | Record |
| --- | --- |
| Date, owner and candidate |  |
| Stage evidence | Decision Sessions, production date range and data source. |
| Product usage | Relevant Career, Compare, Save, tool and return behaviour. |
| High-intent journey | Real sequence from decision to action; no identity or free text. |
| Action evidence | Education, employer, job or affiliate action data where applicable. |
| Repeated user need | Observed feedback or interview evidence, separated from conjecture. |
| Provider / employer interest | Evidence of real supply or customer demand. |
| Proposed model | Referral, optional B2C convenience, B2B product, research, other. |
| User value | Why the capability helps after the free decision. |
| Free-core check | Confirm no fact, score, ranking, filter, Compare or calculation is gated. |
| Independence check | Confirm no payment can influence data, score, ranking or recommendation. |
| Privacy and source rights | Data minimisation, consent, retention, licensing and legal-review needs. |
| Technical / operational cost | Product, data, security, accessibility, performance, SEO and support cost. |
| Metrics and guardrails | Primary metric, required sample, Decision Session and trust guardrails. |
| Stop condition | What ends the experiment or proposal immediately. |
| Decision and next action | Reject, observe, prepare, test or operate; link evidence. |
